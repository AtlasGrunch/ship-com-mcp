# Ship.com MCP Server

The Ship.com MCP server connects AI assistants and agents to a Ship.com account.

It can check and create orders, compare shipping rates, buy and void labels, schedule pickups, manage customers, send customer email, and retrieve shipping reports. Every request uses the same account permissions, balances, and safety checks as the Ship.com web app.

## Connect

Server URL: `https://app.ship.com/mcp`

Transport: MCP Streamable HTTP

Authentication: Ship.com access token or supported OAuth sign in
